aso API
API Endpoint
FORMAT: 1A HOST: https://[organiser_url, ask from tuki@torneopal.fi]

Most API calls require an api_key. You need to get this key from the competition organiser.

Use the api_key only between your server and the competition server. Never embed the key to a web page or an application.

Results are cached for up to 1 minute unless otherwise stated.

Pagination: page_size and page_number parameters are available in most calls. Use page_size to set the maximum number of results per page, and page_number to retrieve a specific page of results.

Get competition detailsGET/taso/rest/getCompetition{?api_key,competition_id}
Notes:

rules_<language_code> fields are returned per configured language of the competition (e.g. rules_fi, rules_en).

regions, categories and clubs are only returned when requested via the extra_fields query parameter (comma separated, e.g. extra_fields=regions,categories,clubs).

areas is only returned for competitions organised by a private organiser.

meals is only returned for competitions with accommodation/product rights enabled.

Get categoriesGET/taso/rest/getCategories{?api_key,competition_id,category_id,season_id,all_current,extra_fields}
Returns a list of categories (series/leagues) with comprehensive metadata including competition info, sport, gender, age group, team counts, statistics configuration, and ranking rules. Supports filtering by competition, category, season, or all current categories. Use extra_fields to include nested groups, teams, or phases per category. At least one of competition_id, category_id, season_id, or all_current is required.

URI ParametersHide
api_key
string (required) 
API key got from provider

competition_id
string (optional) Example: spljp15
Competition id. Can be comma-separated for multiple competitions.

category_id
string (optional) Example: VL
Category id

season_id
string (optional) Example: 2015
Season id. Can be comma-separated for multiple seasons.

all_current
number (optional) Example: 1
Set to 1 to get all current (non-archived, non-hidden) categories.

extra_fields
string (optional) Example: groups,teams,phases
Comma separated list of nested structures to include. Available: groups, teams, phases. These are loaded via getCategory for each result, so use sparingly with large category lists.

Get calendarGET/taso/rest/getCalendar{?api_key,start_date,end_date,date,calendarmonth,category_id,sport_id}
Returns matches within a date range for calendar display. Supports filtering by category and sport. When calendarmonth is provided, the date range is expanded to full calendar weeks (Monday to Sunday). When sport_id=beach, also returns beach_tournaments array with category dates. Only published, non-test, non-rescheduled matches from public competitions are included.
