Aloitusnäkymä = pelaajakortin oletusvälilehti.
· Kausifokus (makro, IDP-kausitavoite) + jaksofokus (meso, 1–6 vk lohko) ylimpänä — kaksisyklimalli näkyvissä.
· Tilanne yhdellä silmäyksellä: viimeisin mittaus, edistymä, seuraava review, kypsyys.
· Seuraava askel selvänä: kirjaa review / avaa tavoite / arvioi.
· Drill-down välilehdillä: Fyysinen/Tekninen/Peli = raakadata, Kehitys = tavoite, Arviointi = havaittu.
· Kypsyysneutraali (§28): PHV-herkkä 🌱, ei punaista hälytystä pre-PHV-fysiikasta.
