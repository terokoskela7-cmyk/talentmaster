Silmukka sulkeutuu — putkesta tulee sykli.
· Laukaisin — jakso umpeutuu (4c `tmJfUmpeutunut`) → "Sulje jakso".
· Prosessi ensin — tehtiinkö harjoitukset + läsnäolo (4d/K2). Vaikutusta ei väitetä ilman toteumaa.
· Kaksi näkökulmaa — pelaajan itsearvio + aikuisarvio → kalibraatio (näkeekö pelaaja itsensä osuvasti; VP-työkalu, ei pelaajalle syyllistävänä). Video ennen/jälkeen tulossa (§15 media[]).
· Aikuisarvion antaja = pelaajan oma valmentaja (§4/§37): joukkuevalmentaja omat joukkueen pelaajat (Master), talenttivalmentaja talentit, VP oversight + kaikki.
· Tulos pehmeä — parani / ennallaan–jatka / vaihda. §28: hidas kehitys = normaali, ei moite.
· Seuraava fokus — silta (Vaihe 5) ehdottaa → uusi jakso. Kaari kasvaa → elävä kehitystarina.
· Kaikki pikakentistä (`jaksofokus_historia[]`, §26). VP/valmentaja-näkymä (§7.22 ei koske).
