Pelaaja · ADAR (4)
Havaitse · Päätä · Toimi · Arvioi = pelin lukemisen sykli (skannaus → havainto → päätös → suoritus → reflektio). Jordetin skannaustutkimus + havainto-toiminta-malli. Konsensus useasta arvioijasta (anti-anchoring), ikäportitettu §28.
Havaitse = scan/perceive Päätä = decide Toimi = execute Arvioi = review
Valmentaja · osaaminen (3)
Havainnointi · Kalibraatio · Reflektio = ISCF-valmentajafunktiot "read & react to the field" + "learn & reflect", kalibraatio inter-rater-reliabilitystä. Mitataan samasta havaintodatasta (arvioija + rooli).
Havainnointi = kattavuus Kalibraatio = ero VP:hen ↓ Reflektio = päivittää arvionsa
Vartijat (samat kuin muut kaaret)
Datataso: 1 havaintokierros = lähtöpiste · 2 = suunta · ≥3 = kaari (ei keksittyä viivaa). · §28: ikävaihe (U11 ≠ U16), pre-PHV suunta ei rankaisu. · §7.22: pelaajalle vain oma kasvu, ei lukuja/vertailua. · Aikuisdata (valmentaja): kehittävä, ei rankaiseva; §37 roolit (valmentaja itse + VP mentoroi). · Johdetaan raakadatasta — ei uutta kirjausta havaintohetkellä.
