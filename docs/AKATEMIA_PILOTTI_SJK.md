# Akatemiapilotti — SJK Juniorit (räätälöity Taso 2 -tarjous)

> Laadittu 2026-07-01. Räätälöity `AKATEMIA_PILOTTITARJOUS.md`-pohjasta **SJK:n todelliselle tilanteelle**. Kotimainen Taso 2 -validointikohde (BP4B / BP5 ARPU-eriytys).
> **EI juridinen/hinnoitteluneuvonta** — sopimus tarkistutettava juristilla; hinta validoidaan tässä keskustelussa.
> Kytkeytyy: tehtävä #86 (SJK sopimus + valmentajakoulutus elokuu → go-live syyskuu), #85 (Sibbo-malli), CLAUDE.md §9/§30.

## 1. Miksi SJK on oikea ensimmäinen akatemiakohde
- **Jo pilottiseura, data olemassa:** 61 pelaajaa tuotu; **H-H-testidata valmiina** (`d1_taso`/`hh_taso` 58 pelaajalla, `d2_taso` 56, hh_viimeisin/TSI) — recalcHH ajettu (§30). Akatemia näkee arvon *heti olemassa olevan datan päälle*, ei tyhjästä.
- **Ammattilaisseuran akatemia** (Veikkausliiga) → aito Taso 2 -ostaja, ei grassroots.
- **Aikataulu osuu:** #86 mukaan sopimus + valmentajakoulutus **elokuu** → go-live **syyskuu**. Akatemiapilotti = SJK:n syksyn käyttöönotto, ei uusi erillinen liike.
- **Tyttöjoukkueet mukana** → RAE + kypsyys erityisen relevantti (tytöillä eri herkkyysikkunat, aikaisempi kypsyminen) → vahva demonstraatiokohde.
- **Suhde olemassa** → lämmin, ei kylmä myynti.

## 2. Arvolupaus SJK:lle — mitä olemassa olevan datan *päälle* saadaan
SJK:lla on jo fyysinen taso (H-H). Taso 2 tuo sen päälle sen mitä data yksin ei kerro:
- **Biologinen ikä (PHV):** yksi kasvumittauskierros (pituus/paino/istumapituus) → jokaisen pelaajan kypsyysvaihe → **"onko tämä pelaaja hyvä vai vain aikaisin kypsynyt?"** Tämä on akatemian "aha"-hetki.
- **RAE-korjaus:** paljastaa alivalitut myöhäissyntyneet — SJK:n oman valinnan sokeat pisteet näkyviin.
- **Herkkyysikkuna-signaalit:** Hidden Gem (korkea tekniikka + matala fysiikka pre-PHV), tekninen varhaiskehitys → **löydä lahjakkuudet joita ikäluokkapeli piilottaa.**
- **Syvänäkymä + Head of Talent -kokonaiskuva** (VP/akatemiajohtaja) + valmentajakalibraatio.
- **Perhekerros harjoitegeneraattorilla** → pelaajien päivittäinen sitoutuminen + perheiden pysyvyys (dropout-suoja).
- **Digitaalinen passi** → SJK:n kehittämä data seuraa pelaajaa (myös jos siirtyy — arvo säilyy seuralle referenssinä).

## 3. Pilotin kohde ja laajuus
- **Kohde:** SJK:n **2–3 talenttiryhmää / ikäluokkaa** (sis. vähintään yksi tyttöjoukkue kypsyys-demonstraatioon).
- **Käyttäjät:** akatemiajohtaja / Head of Talent + talenttivalmentajat + pelaajat + perheet.
- **Sisältö (Taso 2 täysi):** olemassa oleva H-H + **kasvumittaus→PHV** + RAE-korjaus + herkkyysikkuna-signaalit + syvänäkymä + ADAR + VAI+ + Head of Talent -raportointi + pelaaja/perhe-app + passi.

## 6. Mitä SJK:lta pyydetään (vastapalvelu pilottihinnasta)
- Nimetty yhteyshenkilö (akatemiajohtaja / Head of Talent) + palaute talenttiarvosta.
- **Referenssilupa** (nimellä) — kriittinen sekä kotimaiseen että kansainväliseen myyntiin ("suomalainen Veikkausliiga-akatemia käyttää").
- Sitoutuminen kasvumittauskierrokseen syyskuussa (PHV-arvon todentaminen).
- Suostumusten kerääminen aktiivipelaajille (nykyinen 6/61 → tavoite go-liveen).

## 7. Seuraavat askeleet (konkreettinen käynnistys)
1. **Ota yhteys SJK:n akatemiajohtoon** (nykyinen VP-kontakti vp.sjk@talentmaster.fi kautta) → sovi elokuun tapaaminen.
2. **Räätälöi `SIBBO_PILOTTISOPIMUS.md`-pohja** Taso 2 -sisällölle + tämä hinnoittelu → SJK-sopimusluonnos (voin tehdä tämän seuraavaksi).
3. **Valmistele kasvumittaus-protokolla** valmentajakoulutukseen (Testaus_v9 kasvumittaus jo olemassa, §25).
4. **Kirjaa todellinen maksuhalukkuus takaisin** BP4/BP5:een keskustelun jälkeen.
