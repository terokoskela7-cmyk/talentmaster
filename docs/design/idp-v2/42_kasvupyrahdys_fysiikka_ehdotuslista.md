# 42 · Kasvupyrähdys-fysiikka: ehdotuslista (Teron hyväksyttäväksi)

> **Tämä lista ei valitse mitään.** Kasvupyrähdyspelaajan (PH) fysiikkaharjoite näytetään toimintakortissa vain jakson omasta fysiikkasnapshotista, kunnes Tero on hyväksynyt tämän listan. Fysiikkalinja on Teron / TalentMasterid Oy:n aineistoa, joten turvallisuusvalinta kuuluu Terolle eikä koodille.
> Luotu: `node scripts/phv_fysiikka_ehdotuslista.cjs` (lukee lähdeaineiston; kenttien sanatarkat PHV-tekstit alla).

## Miten luettava

- **PHV-vaiheet:** ennen (PRE) · nyt (PH, kasvupyrähdys) · jälkeen (POST/AN) — kanoninen sanasto (CLAUDE.md §14). Lähteissä on vain yksi PHV-kenttä per harjoite (`phv` / `phv_ohje` / `phv_ok`), ei erillisiä ohjeita ennen / jälkeen.
- **Konekatsaus** on mekaaninen luokittelu lähteen omasta PHV-tekstistä, **ei kliininen arvio**: *sellaisenaan* (teksti alkaa "Normaali" tai kertoo liikkeen turvalliseksi) · *kevennetty ohje* (lähteellä oma kevennetty versio) · *osa pois* (teksti poistaa osan liikkeestä → vain kevennettynä) · *ei ehdoteta* (ei PHV-ohjetta).
- **Ennen / jälkeen:** ehdotus on käyttää samaa harjoitetta **normaalilla ikävaiheohjeella** (leikkijä / rakentaja / showcase) — ellei Tero toisin päätä. Lähteissä ei ole PRE/POST-kohtaisia rajoituksia.
- **HPP-pankki** on kuntoutusprotokollien harjoitekirjasto (`phv_ok`): ei ehdoteta automaattiseen valintaan; lista on mukana, jotta Tero voi merkitä sopivat.
- **Tero:** täytä viimeinen sarake (ennen / nyt / jälkeen: kyllä / ei / vain kevennettynä). Hyväksytty lista viedään koodiin omana PR:nään + testit.
